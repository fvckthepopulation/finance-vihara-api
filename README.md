# vihara-finance-api

Laravel 13 backend for **Vihara Finance** — treasury & accounting for the
viharas under Yayasan Dhammavihara Indonesia.

Scope: kas/bank, rekonsiliasi, petty cash, pembayaran, penerimaan, jurnal,
laporan (P&L, balance sheet, trial balance), rekap komisi platform
KalyanaMitta (future integration).

## Stack

- Laravel 13 (PHP 8.4)
- Postgres 16
- Sanctum (personal access tokens)
- Spatie Permission (roles + abilities)

## Local development

```bash
cp .env.example .env
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve --port=8400
```

## Configuration

Required env vars:

| Var | Example | Notes |
|---|---|---|
| `APP_KEY` | `base64:...` | Generated by `key:generate` |
| `APP_URL` | `https://api.your-domain.com` | Public URL |
| `DB_HOST` | `127.0.0.1` (dev) / `172.17.0.1` (prod) | Postgres host |
| `DB_DATABASE` | `vihara_finance` | |
| `DB_USERNAME` | `vihara` | |
| `DB_PASSWORD` | `<strong>` | |
| `FRONTEND_URL` | `https://app.your-domain.com` | For CORS allow-origin |
| `SANCTUM_STATEFUL_DOMAINS` | `app.your-domain.com` | Comma-separated |
